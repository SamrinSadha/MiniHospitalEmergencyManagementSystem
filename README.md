# Mini Hospital Emergency Management System

## Introduction

The Mini Hospital Emergency Management System is a Java-based application designed to manage patients in a hospital environment. The system demonstrates the use of different data structures to manage patient records, emergency patients, treatment history, and patient visit history.

## Data Structures Used

### 1. Binary Search Tree (BST)

The Binary Search Tree is used to store patient records using Patient ID as the key.

Operations:

* Insert a patient
* Search for a patient
* Delete a patient
* Display patients using in-order traversal

### 2. Queue

A Queue is used to manage patients waiting for emergency treatment.

Operations:

* Enqueue a patient
* Dequeue a patient
* Display waiting patients
* Handle an empty queue

The Queue follows the FIFO (First-In, First-Out) principle.

### 3. Stack

A Stack is used to store completed treatment records.

Operations:

* Push a treatment record
* Pop the most recent treatment record
* Display treatment records
* Handle an empty stack

The Stack follows the LIFO (Last-In, First-Out) principle.

### 4. Singly Linked List

A Singly Linked List is used to maintain each patient's previous hospital visit history.

Operations:

* Add a visit
* Remove a visit
* Search for a visit
* Display visit history
